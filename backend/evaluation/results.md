# HealthIntel Evaluation Results
> Generated by running evaluation scripts inside the Docker container.
> **Do not fabricate metrics** — run the scripts to populate this file.

---

## How to Run Evaluations

```bash
# Start the full stack first
docker compose up --build -d

# Then run:
docker compose exec backend python evaluation/evaluate_classifier.py
docker compose exec backend python evaluation/evaluate_rag.py
```

## 3. OCR (EasyOCR)

OCR evaluation requires test images with known ground truth text.
Character Error Rate (CER) = edit_distance(pred, ref) / len(ref).

> CER evaluation requires a labelled prescription image dataset.
> This is not included as no public labelled prescription dataset is used.

---

## 4. Biomedical NER

Formal NER evaluation requires gold-standard annotated data.
The NER pipeline uses scispaCy/spaCy + regex fallback.

> Entity-level P/R/F1 requires a labelled benchmark such as i2b2 or n2c2 clinical NLP datasets.
> These datasets require data use agreements and are not included in this project.
> The NER pipeline is validated functionally via unit tests (`tests/test_api.py`).

## Notes

- All metrics above are honestly labelled as pending until the scripts are run.
- The classifier training data is intentionally small (90 samples) to keep the project self-contained.
- A production system would use thousands of labelled examples from clinical NLP datasets.
